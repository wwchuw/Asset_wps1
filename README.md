# ตรวจทรัพย์สิน (PWA + Google Sheet)

เว็บแอปตรวจทรัพย์สินบนมือถือ ใช้ Google Sheet และรูปใน Google Drive ชุดเดิมจาก AppSheet
ไม่ต้องย้ายข้อมูล สติ๊กเกอร์ QR เดิมใช้ได้ทันที

## ส่วนประกอบ

| ไฟล์ | อยู่ที่ไหน | หน้าที่ |
|---|---|---|
| Code.gs | Apps Script ใน Google Sheet | API อ่าน/เขียนข้อมูล |
| ไฟล์ที่เหลือทั้งหมด | GitHub Pages | หน้าแอปบนมือถือ |

ข้อมูลที่แอปเขียนลง Google Sheet
- คอลัมน์ `ตรวจทรัพสินย์งบ_<ปีงบ>` ในชีทหลัก (ปีใหม่สร้างคอลัมน์ให้อัตโนมัติ) ดูผลตรวจใน Sheet ได้เหมือนเดิม
- ชีท `AuditLog` ประวัติทุกครั้งที่ตรวจ: เวลา ปีงบ รหัส ผลตรวจ หมายเหตุ ผู้ตรวจ พิกัด GPS
- รูปใหม่บันทึกในโฟลเดอร์รูปเดิม ชื่อ `<รหัส>.รูปภาพ.<วันเวลา>.jpg` และอัปเดตคอลัมน์ รูปภาพ (รูปเก่ายังอยู่)

## ขั้นที่ 1: ตั้งค่า Apps Script (ทำใน Google Sheet เดิม)

1. เปิด Google Sheet ที่ AppSheet ใช้อยู่ → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดที่มีอยู่ แล้ววางเนื้อหาไฟล์ `Code.gs` ทั้งหมด → กดบันทึก (ไอคอนแผ่นดิสก์)
3. ตรวจค่าใน `CONFIG` ด้านบนของโค้ด
   - `SHEET_NAME` ชื่อชีทข้อมูล (ของเดิมคือ `Sheet1`)
   - `IMAGES_FOLDER_ID` ใส่ ID โฟลเดอร์รูป: เปิดโฟลเดอร์รูปใน Google Drive แล้วคัดลอกส่วนท้าย URL
     เช่น `drive.google.com/drive/folders/`**`1AbCdEf...`** (ถ้าเว้นว่าง จะหาจากชื่อโฟลเดอร์)
4. ตั้งรหัสทีม: เมนูซ้าย **การตั้งค่าโปรเจ็กต์ (⚙)** → **Script properties** → Add script property
   - Property: `TEAM_KEY`
   - Value: รหัสยาวๆ ที่เดายาก เช่น `ssn1-ตรวจ-7Qm4-xR92` (ใครมีรหัสนี้ใช้แอปได้ แจกเฉพาะทีม)
5. กลับไปที่หน้าโค้ด เลือกฟังก์ชัน `testSetup` ในแถบด้านบน → กด **Run**
   - ครั้งแรกจะขออนุญาต: Review permissions → เลือกบัญชี → ถ้าขึ้น "Google hasn't verified this app"
     ให้กด Advanced → Go to (ชื่อโปรเจ็กต์) (unsafe) → Allow
     (เป็นเรื่องปกติของสคริปต์ที่เราเขียนเอง)
   - ดู Execution log ควรขึ้นว่า "ทรัพย์สิน 109 รายการ, มีรูป 109 รายการ"
6. **Deploy → New deployment** → กดไอคอนเฟือง เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

"Anyone" หมายถึงใครก็เรียก URL ได้ แต่ทุกคำสั่งต้องมีรหัสทีมที่ถูกต้อง ถึงจะอ่านหรือเขียนข้อมูลได้

## ขั้นที่ 2: เปิดสิทธิ์ดูรูป

แอปแสดงรูปผ่านลิงก์ภาพย่อของ Google Drive ต้องตั้งโฟลเดอร์รูปเป็น
**แชร์ → ทุกคนที่มีลิงก์ → ผู้มีสิทธิ์อ่าน** (ลิงก์ของแต่ละรูปเดาไม่ได้ แต่ใครได้ลิงก์ไปก็เปิดดูได้)

ถ้าไม่อยากเปิดแชร์ รูปจะแสดงเฉพาะในเบราว์เซอร์ที่ login Google ด้วยบัญชีที่มีสิทธิ์เข้าโฟลเดอร์นั้นอยู่แล้ว

## ขั้นที่ 3: ใส่ URL และเอาแอปขึ้นเว็บ

1. แก้ `config.js` บรรทัด `apiUrl` ใส่ Web app URL จากขั้นที่ 1
2. สร้าง repository บน github.com (เช่น `asset-audit`) → อัปโหลดไฟล์ทั้งหมด ยกเว้น `Code.gs` และ README
   (index.html, app.js, style.css, config.js, sw.js, manifest.webmanifest, โฟลเดอร์ icons)
3. Settings → Pages → Branch: `main` → Save รอ 1–2 นาทีจะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/asset-audit/`
4. เปิดลิงก์บนมือถือ ใส่รหัสทีมกับชื่อผู้ตรวจ แล้วกด "เพิ่มลงในหน้าจอหลัก"

## ใช้งาน
- สแกน QR สติ๊กเกอร์เดิม หรือพิมพ์รหัส → เลือกผลตรวจ → บันทึก ("บันทึกและสแกนต่อ" กลับไปที่กล้องทันที)
- ไม่มีเน็ต: ผลตรวจเก็บในเครื่อง ส่งเข้า Sheet อัตโนมัติเมื่อต่อเน็ต (รูปใหม่ต้องมีเน็ต)
- ปีงบเปลี่ยนเองทุก 1 ต.ค. เลือกปีเก่าดูย้อนหลังได้
- เมนู ⋯ → เปิด Google Sheet เพื่อดูหรือพิมพ์รายงาน

## แก้ไขภายหลัง
- เพิ่ม/แก้ทรัพย์สิน: แก้ใน Google Sheet ตามปกติ แล้วกด "โหลดข้อมูลใหม่" ในแอป (อย่าเปลี่ยนชื่อหัวคอลัมน์)
- แก้ Code.gs แล้ว: Deploy → **Manage deployments** → ✏️ → Version: **New version** → Deploy
  (URL เดิมใช้ต่อได้ ไม่ต้องแก้ config.js ถ้ากด New deployment จะได้ URL ใหม่)
- เปลี่ยนรหัสทีม: แก้ `TEAM_KEY` ใน Script properties ทุกคนต้องเข้าใหม่ด้วยรหัสใหม่
- แก้ไฟล์แอปแล้วมือถือไม่อัปเดต: เปลี่ยน `VERSION` ใน sw.js
- เปลี่ยนตัวเลือกผลตรวจ: แก้ `statuses` ใน config.js

## หลังยกเลิก AppSheet
Google Sheet และรูปใน Drive ยังอยู่ครบ แอปนี้ใช้ต่อได้ทันที
ชีท `User` และ `Login` ที่ AppSheet ใช้เก็บรหัสผ่านเป็นข้อความธรรมดา แอปนี้ไม่ได้ใช้ ควรลบทิ้ง
